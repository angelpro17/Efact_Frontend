# EFACT Frontend

Aplicación web para visualización de documentos electrónicos (PDF, XML, CDR) del sistema EFACT.

## Tecnologías

- Angular 18
- TypeScript
- Standalone Components

## Instalación

```bash
npm install
```

## Ejecutar

```bash
npm start
```

La aplicación estará disponible en `http://localhost:4200`
